# Plataforma Académica Básica

## Integrantes

- Ricardo Herrera Calero

## Descripción

La Plataforma Académica Básica es un proyecto desarrollado como ejercicio de la asignatura Ingeniería de Software III.

El proyecto presenta una interfaz web sencilla orientada a la consulta de información académica. La plataforma permitirá visualizar información básica sobre estudiantes, cursos y recursos académicos.

El objetivo principal del proyecto es aplicar los conceptos de control de versiones y trabajo colaborativo mediante Git y GitHub, utilizando ramas, commits, pull requests y revisión de cambios.
